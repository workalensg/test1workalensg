
# Gevril Custom Shopify Theme

## Опис:
Ця тема була створена на основі дизайну в Figma для бренду Gevril. Вона включає такі секції:
- Hero
- Collections Grid
- Product Highlight
- Video Banner
- Reviews
- Newsletter

## Інструкції:
1. **Встановіть Shopify CLI**:
   - [Shopify CLI](https://shopify.dev/docs/themes/tools/cli)

2. **Ініціалізація теми**:
   - Якщо у вас є вже Shopify магазин, підключіться через CLI:
     ```bash
     shopify login
     shopify theme init
     ```

3. **Розгортання на локальному сервері**:
   - Для запуску локально:
     ```bash
     shopify theme dev
     ```

4. **Пуш змін на GitHub**:
   - Створіть нову гілку:
     ```bash
     git checkout -b feature/shopify-theme
     ```
   - Додайте зміни та пуште:
     ```bash
     git add .
     git commit -m "Initial commit of Shopify custom theme"
     git push origin feature/shopify-theme
     ```

5. **Створіть Pull Request**:
   - Перейдіть на GitHub і створіть Pull Request для злиття нової гілки з `main`.
